# RAG AI Chatbot First

Folder ini berisi file pendamping untuk seri video tentang cara membuat RAG AI chatbot menggunakan Python.

Di project ini kita akan mencoba membuat chatbot yang dapat mencari informasi dari dokumen sebelum memberikan jawaban.

## Sebelum mulai

Sebaiknya sudah cukup familiar dengan dasar-dasar Python. Kalau masih ingin mengulang Python, beberapa referensi yang bisa digunakan:

- [W3Schools](https://www.w3schools.com/python/default.asp)
- [freeCodeCamp](https://www.freecodecamp.org/learn/python-v9/)
- [LearnPython.org](https://www.learnpython.org/)
